Privacy note · Last updated October 30, 2026

Privacy, in plain words.

MixMash Studio is a small, independent set of free browser games. There are no accounts, mixmash.games sets no cookies, there are no ads, and we never sell your data.

What we measure

The homepage and the MIXMASH, Front of House, Pitch Riot, MarsScape and Garden OS pages load Cloudflare Web Analytics. It counts page views without cookies, local storage or fingerprinting. It sees the page address, the referring site, your browser and device type, your country (worked out from your IP address) and page-load timing. We only look at the totals. Age of Dave (EMPIRES) and this page do not load it.

What stays in your browser

Game saves and settings live in your browser's own storage (local storage, plus IndexedDB for MarsScape and Garden OS). They are not sent to us, except for MarsScape and Garden OS progress, described below. That includes:

  • Game progress, save slots, options, sound and mute settings.
  • The homepage's light or dark theme, and the last game you opened, so the homepage can offer to pick up where you left off.
  • An offline copy of the site, kept by a service worker so games still open without a connection.

To clear it: open your browser's settings for this site (often under the padlock or site-info icon next to the address) and clear site data for mixmash.games. Garden OS keeps its own saves under davehomeassist.github.io, so clear that too. Clearing removes your saves, so export a backup from the game menu first if a game offers one.

MarsScape online saves

When MarsScape is online, your colony is saved on a small game server hosted by Vercel (mixmash-marsscape-authority.vercel.app). The server stores the colony's game state under a random session ID your browser makes up. No name, email or account is attached. Your IP address is used briefly to limit request floods and is not saved with your colony. To have a MarsScape server save deleted, email us its exported save code, which contains the session ID.

Other services the site uses

  • GitHub Pages hosts mixmash.games. Like any web host, it receives your IP address when you load a page. GitHub privacy statement.
  • Cloudflare Web Analytics, as described above. Cloudflare privacy policy.
  • Vercel hosts the MarsScape save server and the Garden OS progress server. Vercel privacy policy.
  • Garden OS is embedded from Dave's Garden OS project on davehomeassist.github.io. Story Mode can send your game actions to its own progress server (garden-os-theta.vercel.app) under a random session ID, with no name or account.
  • Google Fonts serves typefaces to Pitch Riot, Garden OS and a few studio pages, so Google receives your IP address when they load. Google Fonts privacy FAQ.
  • Ko-fi and GitHub (Send feedback, Source) are plain links. Nothing loads from them until you click, and then their own policies apply. Ko-fi privacy policy.
