Command Basics

EMPIRES plays like a classic RTS. These are the only bindings you need to start.

↑ ↓ / Tab / Enter
In the lobby: pick a civ, switch player/AI, confirm.
Space
Start the skirmish from the lobby.
Left-Click
Select a unit or building.
Left-Drag
Box-select every unit inside the rectangle.
Shift + Click
Add to or toggle the current selection.
Right-Click
Command the selection: move, attack, gather, or set a rally point.
Minimap drag
Navigate the camera around the map.
Action panel
Lower right — train units, age up, and open build placement.
Esc
Cancel an active build placement preview.
H
Toggle the game's own in-match help panel.
F3
Toggle the performance overlay.
