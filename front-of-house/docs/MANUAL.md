# Front of House player guide

Run a concert, settle its money, and build a career from Oak St. Lot to Split Acre. This guide covers the existing playable controls. The 3D view is an optional preview.

## Finish your first show

1. **Book.** Read the act's draw, usual ticket price and ask. Open **How the deals work** if a deal is unfamiliar, then choose an available deal.
2. **Build.** Choose **Suggested layout** for a working starting point. Read the readiness line and **Details**, adjust the room, then choose **Lock the layout**. On a phone, layout actions are under **Actions**.
3. **Promote.** Set the ticket price and advertising. Compare the forecast range with capacity and the amount due before doors. Open the doors only when the bill is affordable.
4. **Show.** Watch the night or use **Skip to the problem**. Read each incident response's cost and consequence before choosing. A paid response needs cash at that moment.
5. **Settle.** Read revenue, costs, the artist's payout and the crowd's result. **Sign the settlement** finishes the night; closing the window leaves it unsigned.
6. **Done.** Review the career checklist and book the next show. If the next opening is unaffordable, the game explains the shortfall.

A good crowd and a profitable show are different results. Judge the complete settlement rather than ticket income alone. A forecast is a range, not a promised outcome.

## Choose a deal

| Deal | What to check |
| --- | --- |
| Guarantee | The artist is paid up front. Check the complete opening bill and what remains for incidents. |
| Door deal | Read which positive balance the artist shares. Eligibility depends on the act and your relationship. |
| Sponsor | Available at Split Acre. New sponsor bookings fix the site ticket price to the main act's usual price; advertising remains adjustable. |

The offer card and accepted terms govern the booking. An older imported show may retain its original rules; its detail window explains that instead of silently changing the contract.

## Build and inspect

**Select** inspects an existing object. Choose an equipment tile before placing anything. The cursor and readiness message explain invalid positions. Rotate the next object with **Rotate** or **R**. Changing the camera never rotates equipment in the saved layout.

Use **Details** to inspect and remove objects by name. **Remove** or the bulldozer deletes objects; **Clear** asks before removing the layout. **Undo** and **Redo** apply during the current Build session. That history does not survive loading a save or leaving Build.

Sightline shading shows the room's calculated clear and blocked areas. The capacity, power and readiness readouts remain authoritative; decorative guests, seating guides and the 3D side-stage annex do not create extra saleable capacity or buildable tiles.

## Move the view

The top strip has **−**, **Fit**, **+** and **Turn**. Fit returns to the whole site. A middle-button drag pans; the mouse wheel zooms. Tab to the board to use its keyboard controls.

Open **Menu → Camera → Try 3D preview** for the dimensional view. In Select, tap to inspect and drag to orbit. Two fingers pan and pinch. With a placement tool, a tap places and dragging previews; **Drag camera while placing** explicitly changes that gesture. The Camera window also offers orbit buttons and **Wide**, **FOH**, **Stage** and **Plan** presets. Split Acre adds **Side stage**.

The normal entry route starts in classic view. A Camera-window toggle lasts for the session. The explicit [3D preview entry](https://mixmash.games/front-of-house/?renderer=3d) requests 3D when reopening. Camera views and zoom do not change show outcomes.

If 3D fails, classic view keeps the show available. Open Camera to read its status or choose **Retry 3D**. Export the save before clearing any browser data.

### Split Acre overview

When zoomed in on a desktop, the site overview shows the layout, camera target and visible ground. Click or drag within it to pan without placing equipment. It follows the view's rotation; the 3D version includes the fixed annex.

Focus the overview with Tab. Arrow keys pan, Enter or Space centers the site, Home returns to Fit, and Escape returns focus to the board. The overview hides at Fit, on phones, or when there is no safe space beside the controls.

## Work with the venue

| Venue | Useful controls |
| --- | --- |
| Oak St. Lot | Start with the layout and incident loop. Optional live operations make admission, bar queues and a transferable worker visible. |
| Fathom Hall | **Ticketing** compares direct and outsourced presales. Check the fee and frozen receipt as well as advance sales. |
| Loam Shell | **Seats and lawn** separates prices, forecasts and receipts. Its Room page explains the included shell system and sloped sightlines for new marked bookings. A placed portable PA replaces house coverage and can reduce it. |
| Split Acre | Choose the side act through **Stage bill** before accepting the main deal. **Stage accounts** separates Main, Side, Site and Cash. Guests buy one site ticket; side-stage attendance is not extra ticket revenue. |

**Sound and views** reports the Festival house system and calculated viewing areas for new bookings. The **Delay** tool adds coverage beyond the main system where a placed tower reaches open floor. Overlapping areas count once, and a placed portable PA disables the delay benefit. Check the Delay page for coverage and recurring rental/operator costs before opening.

An act cannot play both Festival stages in one booking. Earlier-tier headliners need the relationship shown in the bill. If no side act accepts a door deal, choose another venue rather than opening a second contract.

### Outdoor curfew

For new Loam Shell and Split Acre bookings, a noise curfew ends the set at the reported incident time. **End the set** is free. **Appeal and finish the song** costs $400 and extends the set by five minutes, up to 23:00. Each held night has its own timing.

Open **Set time** to read the start, actual end and minutes lost. Early closing reduces scheduled walk-up admissions and bar income; presales remain admitted. The response button, playback and signed receipt use the same end time. Older unmarked bookings retain their original terms.

### Held nights

For a Loam Shell hold, finish and settle the current night before deciding what happens next. **Held nights → Continue** shows the next opening and remaining cash. **Cancel** quotes the unplayed-night fee. Completed nights keep their earnings and reputation; cancelling does not charge another opening or award unplayed-night progress.

Read the final cash before signing. A cancellation can leave debt, and continuing is unavailable when its opening cannot be paid.

## Optional operations and career tools

Use the available detail windows to read a system's terms before enabling or changing it. Features apply where their controls and recorded booking support them.

- **Live operations:** the show starts paused. Watch admission wait, bar demand and worker status. Sending the transferable worker to admission reduces bar capacity; travel takes time. Returning the worker restores future service, not missed sales. Reload preserves the recorded operation.
- **Food and facilities:** place the relevant equipment, read the plan's staffing, supply and cost, and inspect the receipts. Queue colors illustrate recorded groups; the same admitted guest is not a second ticket sale when visiting a service.
- **Development:** compare project costs, progress and effects. A project advances through its recorded conditions; buying it is not the same as finishing it.
- **Equipment:** enable the inventory and cash journal, then compare buying, deploying, renting and selling. An owned item must be assigned as described by its controls. Available cash includes purchases, sales, research and show movements; itemized history is separate from the full retained totals.

The crowd is a representative display. Use the numeric counts and receipts when judging admissions, departures, service demand or money.

## Keep and recover your game

The game saves automatically in the current browser after each step. To keep a portable copy:

1. Open **Menu → Save and load → Show my save code**.
2. Copy the entire code somewhere safe.
3. In the destination browser, open **Save and load**, paste it into **Save code**, and choose **Load this code**.
4. Check the room, phase and cash before continuing.

Loading a valid code replaces the current game; export that game first if you need both. A damaged code or a code from another game is refused without replacing the current save. Starting a new game replaces the current run after its confirmation.

Previously visited content can reopen offline from the browser cache. Warm the 3D preview while online before relying on it offline. A new browser, cleared storage or uncached content still needs a connection. Offline recovery does not replace a portable save backup.

## Keyboard and display

These board shortcuts require board focus. Text fields and open windows keep their own controls.

| Key | Action |
| --- | --- |
| Q | Turn the view |
| + / − / 0 | Zoom in / out / Fit |
| Shift + arrows | Pan a zoomed view |
| Arrows in Build | Move the build cursor |
| Enter / Space in Build | Place with the selected tool, or inspect in Select |
| R / B / Delete | Rotate next object / toggle bulldozer / remove under cursor |
| Ctrl+Z or Command+Z | Undo a Build change |
| Ctrl+Shift+Z, Ctrl+Y or Command+Shift+Z | Redo |
| Esc | Close the current window or menu, then cancel a Build tool |
| ? | Open or close Menu |

**Menu → Keys and mouse** lists the current equipment shortcuts. Menu also provides **Dark controls** and **Full screen**. Phone and short-window layouts divide content into tabs or pages; check the selected tab and page controls if a field is not visible. Reduced motion changes presentation, not settlement rules.
