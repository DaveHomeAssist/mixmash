# Beginner recovery experiment protocol

Scope authorized by Dave on October 23, 2026: test existing cheaper plans and
earned earlier venues. This is simulation work, not approval to change balance.
FOH-BAL-01 remains open. No rule, data, save, renderer, version or dependency change.

## Frozen design, before running the comparison

The player problem is distinguishing an unaffordable preferred plan from an
unavoidable career stop. Reuse the original workbench and engine. Four arms use
identical career seeds, a 60 signed-show limit, normal earned unlocks and the
beginner's cheapest affordable incident response:

| Arm | Plan choice when the original beginner has no plan | Venue choice |
| --- | --- | --- |
| fixed | Stop, unchanged original driver | Highest earned |
| adaptive | Cheapest affordable original grid plan, cost then lexical ID; if grid is empty, engine-authored cheapest layout with usual price and zero ads, cheapest legal deal/side act | Highest earned |
| venue | Original beginner policy only | Try earlier earned rooms, nearest first, only when the highest room has no preferred plan |
| combined | Adaptive rule | Try earlier earned rooms, nearest first, only when the current room has no adaptive plan |

The Festival minimum includes the existing required touring-support objects.
No profit or future-outcome optimization. All booking, layout, promotion, opening,
response, signing and venue changes use actual engine actions. Lower rooms are
considered only in Book; a refused nextShow stays an engine refusal. A lower-room
success does not grant new unlocks. Retry the highest earned room next night.
No state injection, reseeding, retries, loans, research, purchases, held runs or
live services. The original six-policy workbench remains byte unchanged.

## Cohorts and measures

Reproduce all six original policies at 1001 through 1100 (600 careers).
Run four arms at 1001 through 1100 for matched historical comparison. The former
1081 through 1100 holdout is already public and is replication, not fresh validation.
Freeze this protocol and implementation before running a fresh 2001 through 2100
validation cohort. No selection or parameter changes after viewing validation.
Any strategy revision requires new validation seeds. Integrity fixes must be
disclosed and must not silently replace failed runs.

Report completion counts, all stop reasons, signed shows, unlock/reach counts,
completion lengths, final/minimum cash, losses regained within three shows with
censoring, and signed-show quality. Paired completion wins/losses and common-prefix
parity separate intervention effects from unrelated driver drift. Compare cash at
show 1, 3, 5, 10, 20 and 60 with terminal states carried forward and absorption
counts shown; this is a fixed decision-horizon cash measure, not ongoing income
after completion. Terminal cash alone compares different career lengths.

Record every intervention, opening quote, cash change, later cash recovery and
eventual completion. Report venue opportunities separately from successful
recoveries; zero triggers means no estimated venue benefit, not proof of no value.
The published random seed 1001 is a separate positive control for the venue route,
not a beginner outcome. Validate cheapest-layout fallback at beginner seed 1093.

## Acceptance and limits

Original cohort counts and source/report digests must reproduce. Disabled recovery
must match original traces/final states. All four arms must replay, maintain exact
opening/response/signing accounting, preserve normalized saves and use only public
planning inputs. Run the workbench integrity suite, the repository unit/build
checks and unchanged Lot/tier/career baseline generators. No UI is changed, so this
experiment makes no new browser, physical-device or human difficulty claim.

Deliver reproducible scripts, source-bound machine-readable results, focused
regressions and findings on an unmerged branch. Recommend guidance, further economy
research or retention based on measured limitations. Do not infer sustainable
recovery from one legal continuation. Existing human acceptance and D12 stay open.
